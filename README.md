# DELTA-ECO

Project site for **DELTA-ECO** — Lebanon's first open-architecture delta robotic arm.
Built by Team J2M at AUST, in partnership with Raymond Feghali Co. (2026).

**Live site:** https://mounir187.github.io/delta-eco/

## About

A single static page (`index.html`) featuring:

- An interactive 3D delta-robot model (Three.js) with real delta inverse kinematics
- Automation pipeline, capabilities, real-time telemetry, and an operator-interface mockup
- A dark, minimal product design

No build step — open `index.html` in a browser, or serve the folder statically.
