About Delta-Eco

A local delta robot built like a real machine, not a black box.

Delta robots have defined high-speed handling in food, electronics, pharma, and packaging for decades, but access to that class of automation has been limited by cost, vendor lock-in, and foreign dependency. Delta-Eco was built to change that for Lebanese industry.

Developed by Team JC2M at AUST in partnership with Raymond Feghali Co., Delta-Eco combines local mechanical design, EtherCAT control, custom C motion software, AI vision integration, and a purpose-built operator interface.

It is not just a prototype arm. It is a complete automation platform with open architecture, deterministic control, and practical factory operating modes.

What used to require a rack of hardware now runs on a single machine.
IgH EtherLab turns a Linux system into a distributed-clock EtherCAT master, while Delta-Eco's C daemon runs a deterministic 1 kHz loop for encoder feedback, inverse kinematics, and three-drive command output with sub-millisecond behavior.
Control Flow

Automation Pipeline

From sensor input to closed-loop telemetry — five deterministic stages execute on every 1 ms cycle.

◉
01. Vision Capture
An industrial camera captures the live conveyor scene as calibrated visual data.
❖
02. AI Detection
YOLO localizes and classifies each target part directly from the running scene.
Σ
03. IK Solver
Custom C inverse kinematics computes θ1, θ2, θ3 from every XYZ target.
⇄
04. EtherCAT Cycle
The 1 kHz EtherCAT loop streams CSP motion commands to all three servo drives.
✓
05. Execution
The arm completes the pick, transfer, palletize, or depalletize motion.

Computer Vision

The robot sees
before it moves.

Delta-Eco uses a Basler Ace2 Pro industrial camera and YOLO-based object detection to identify, classify, and localize objects on a conveyor in real time.

Instead of relying on fixed pick points or mechanical guides, the system adapts to object position dynamically.

Detected objects are converted into XYZ coordinates and fed directly into the inverse kinematics solver for precision targeting.
